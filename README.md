# Search AutoPager

搜索引擎无缝翻页用户脚本：滚动到页面底部时自动加载下一页结果，无需点击分页按钮。

## 支持站点

| 站点                                       | 加载方式                     | 页码分隔条 / 地址栏同步  |
| ------------------------------------------ | ---------------------------- | ------------------------ |
| Google（`google.com`、`google.com.hk` 等） | 抓取下一页 HTML 拼接         | 支持                     |
| Bing（`www.bing.com`、`cn.bing.com`）      | 抓取下一页 HTML 拼接         | 支持                     |
| 百度                                       | 抓取下一页 HTML 拼接         | 支持                     |
| 搜狗                                       | 抓取下一页 HTML 拼接         | 支持                     |
| 360 搜索                                   | 抓取下一页 HTML 拼接         | 支持                     |
| DuckDuckGo                                 | 自动点击原生「更多结果」按钮 | 不适用（站点本身不分页） |

## 功能

- 距离底部约 1500px 时预加载下一页
- 每页插入「第 N 页 · 打开原页面」分隔条
- 滚动时用 `history.replaceState` 将地址栏同步为当前可见页，刷新后停留在该页
- 底部状态提示：加载中、已到最后一页、加载失败（可重试）、触发人机验证（可手动打开下一页）
- 按站点开关：在脚本管理器菜单中选择「在此站点禁用/启用无缝翻页」
- 站内无刷新换词（如百度）时自动重置
- 结果按链接去重，单次最多自动加载 30 页

## 安装

1. 安装脚本管理器扩展：[Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)
2. 打开 [search-autopager.user.js 原始文件](https://raw.githubusercontent.com/mhaibaraai/search-autopager/main/search-autopager.user.js)，管理器会弹出安装页面

> Greasy Fork 是脚本分发站点，本身不运行脚本。发布到 Greasy Fork 时可在「同步」中填入上方原始文件地址，实现随仓库自动更新。

## 维护说明

站点结构变化时只需修改脚本中的 `SITES` 配置：

| 字段                       | 说明                                                            |
| -------------------------- | --------------------------------------------------------------- |
| `container`                | 结果容器选择器                                                  |
| `items`                    | 单条结果选择器                                                  |
| `next(doc)`                | 返回下一页链接元素                                              |
| `anchor`                   | 容器内的分页条，存在时状态条与新结果插在它之前                  |
| `fallback(url)`            | 首页缺少分页条时按 URL 参数推算下一页（搜狗 `page`、360 `pn`）  |
| `clean(url)`               | 移除会导致返回错误页面的参数（Bing 的 `rdr`/`rdrig`/`FPIG`）    |
| `nativeClass`              | 站点按类名前缀清理未知节点时附加的原生类名（Bing 使用 `b_msg`） |
| `blocked(doc, url)`        | 识别人机验证页面                                                |
| `mode: 'click'` / `button` | 点击站点原生「更多结果」按钮                                    |

## 已知限制

- 搜索引擎可能对频繁请求触发人机验证，此时脚本会停止并提示手动打开下一页
- 未登录状态下百度可能只返回有限页数，脚本会在内容重复时显示「已到最后一页」
- 依赖页面脚本渲染的富结果卡片（视频轮播等）在拼接页中可能显示不完整
