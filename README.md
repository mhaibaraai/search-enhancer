# Search Enhancer

搜索引擎增强用户脚本：无缝翻页、去广告、跳转链接直达真实地址、按域名屏蔽结果。

## 支持站点

| 站点                                       | 无缝翻页                 | 去广告 | 直达真实地址               | 域名屏蔽 |
| ------------------------------------------ | ------------------------ | ------ | -------------------------- | -------- |
| Google（`google.com`、`google.com.hk` 等） | 支持                     | 支持   | 不支持（见已知限制）       | 支持     |
| Bing（`www.bing.com`、`cn.bing.com`）      | 支持                     | 支持   | 支持                       | 支持     |
| 百度                                       | 支持                     | 支持   | 支持（自然结果）           | 支持     |
| 搜狗                                       | 支持                     | 支持   | 支持                       | 支持     |
| 360 搜索                                   | 支持                     | 支持   | 支持                       | 支持     |
| DuckDuckGo                                 | 自动点击原生「更多结果」 | 支持   | 不需要（站点本身即为直链） | 支持     |

## 功能

### 无缝翻页

- 距离底部约 1500px 时预加载下一页，每页插入「第 N 页 · 打开原页面」分隔条
- 滚动时用 `history.replaceState` 将地址栏同步为当前可见页，刷新后停留在该页
- 底部状态提示：加载中、已到最后一页、加载失败（可重试）、触发人机验证（可手动打开下一页）
- 结果按真实地址去重，单次最多自动加载 30 页；站内无刷新换词（如百度）时自动重置

### 去广告

隐藏各站点的推广结果与广告区块，包括站点延迟注入的广告。

### 跳转链接直达真实地址

将结果中的站内跳转链接替换为真实地址，点击直接打开目标网站。真实地址全部从页面属性中解析，不额外发起网络请求：

- Bing：解码 `/ck/a` 链接的 `u` 参数
- 百度：自然结果的 `mu` 属性
- 搜狗：结果中的 `data-url` 属性
- 360：标题链接的 `data-mdurl` 属性

### 域名屏蔽

在设置中填写域名（每行一个），匹配该域名及其所有子域名的结果会被隐藏，分隔条上显示本页屏蔽数量。连续 3 页结果全部被屏蔽时暂停加载，可点击「继续加载」。

## 安装

1. 安装脚本管理器扩展：[Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)
2. 打开 [search-enhancer.user.js 原始文件](https://raw.githubusercontent.com/mhaibaraai/search-enhancer/main/search-enhancer.user.js)，管理器会弹出安装页面

> Greasy Fork 是脚本分发站点，本身不运行脚本。发布到 Greasy Fork 时可在「同步」中填入上方原始文件地址，实现随仓库自动更新。

## 设置

在脚本管理器菜单中：

- 「设置」：打开设置面板，开关各项功能并编辑屏蔽域名列表；屏蔽列表支持直接粘贴网址或 `*.example.com`，保存后自动刷新
- 「在此站点禁用/启用 Search Enhancer」：按站点整体开关

## 维护说明

站点结构变化时只需修改脚本中的 `SITES` 配置：

| 字段                         | 说明                                                            |
| ---------------------------- | --------------------------------------------------------------- |
| `container`                  | 结果容器选择器                                                  |
| `items`                      | 单条结果选择器                                                  |
| `title`                      | 结果标题链接选择器，用于去重与域名判定                          |
| `next(doc)`                  | 返回下一页链接元素                                              |
| `anchor`                     | 容器内的分页条，存在时状态条与新结果插在它之前                  |
| `fallback(url)`              | 首页缺少分页条时按 URL 参数推算下一页（搜狗 `page`、360 `pn`）  |
| `clean(url)`                 | 移除会导致返回错误页面的参数（Bing 的 `rdr`/`rdrig`/`FPIG`）    |
| `nativeClass`                | 站点按类名前缀清理未知节点时附加的原生类名（Bing 使用 `b_msg`） |
| `blocked(doc, url)`          | 识别人机验证页面                                                |
| `ads`                        | 广告选择器，或接收 `root` 返回广告元素数组的函数                |
| `realUrl(link, item, title)` | 返回跳转链接对应的真实地址，无法解析时返回 `null`               |
| `hostUrl(item)`              | 标题链接无法还原时用于域名屏蔽的备用地址（Google 使用 `cite`）  |
| `mode: 'click'` / `button`   | 点击站点原生「更多结果」按钮                                    |

## 已知限制

- Google 部分地区的结果链接为加密的 `/goto?url=`，无法离线还原，因此 Google 不做直达替换；域名屏蔽改用结果中显示的网址判定
- 百度的卡片类结果（百科、资讯聚合等）不做直达替换，避免使用其内部伪地址
- 搜索引擎可能对频繁请求触发人机验证，此时脚本会停止并提示手动打开下一页
- 未登录状态下百度可能只返回有限页数，脚本会在没有下一页时显示「已到最后一页」
- 依赖页面脚本渲染的富结果卡片（视频轮播等）在拼接页中可能显示不完整
